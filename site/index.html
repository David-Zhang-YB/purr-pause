为什么需要它

听说过 20-20-20 法则 吗？每工作 20 分钟，看向 20 英尺外的物体 20 秒，可以有效缓解眼疲劳。

但意志力靠不住——所以 Purr Pause 让一只猫每 20 分钟悄悄出现在屏幕中央，温柔地提醒你抬头。

温柔地提醒，不打断你

到点时，一张柔和的休息卡片浮现在屏幕中央，配上倒计时和走动的猫咪。它不抢占焦点，时间一到就自己淡出——你甚至可以随手点掉。

一切都可调

右键托盘 🐱 → 设置，自由调整工作间隔、休息时长，甚至换成你自己的猫——填一张 GIF/PNG 的路径即可。默认值已经够好，但它是你的。

藏在托盘，随叫随到

平时它安静地待在系统托盘里，一个 🐱 图标。需要时右键即可打开设置或退出，不开机自启、不占用任务栏、不打扰你工作。

隐私，是默认设置

Purr Pause 是一个老老实实的本地工具，源码全部开放。下面每一条都可以在 源码 里逐行验证：

  • 不联网v0.1.x 启动后零网络请求——无遥测、无更新检查、无崩溃上报。拔网使用，行为完全一致。
  • 不动注册表运行时代码完全没有注册表读写调用。
  • 不开机自启每次需要你主动启动；卸载就是直接删除 .exe。
  • 不删任何文件运行时从不调用任何文件删除接口。
  • 只写一处所有配置保存在 %APPDATA%\PurrPause\config.json，Windows 标准的每用户配置目录。
  • 可自行验证把 .exe 拖进 VirusTotal 扫一下也行。

下载与安装（Windows 10 / 11）

  1. 点击 「下载 Windows 版」，保存 PurrPause-windows.exe。
  2. 双击运行。
  3. 首次启动时，Windows 会显示 "已保护你的电脑" 蓝色警告。这是因为本应用未购买代码签名证书——所有未签名的小型独立软件都会出现此提示。
  4. 点击 "更多信息" → "仍要运行" 即可（见下方截图的红圈标注）。
  5. 启动后应用会驻留在右下角托盘，看到 🐱 图标即表示运行成功。

下载链接由国内服务器加速分发，速度通常比从 GitHub 直接下载快很多。

常见问题

为什么打开时有安全警告？

因为本应用没有购买代码签名证书（每年 $99–300，现阶段不值得）。所有未签名的独立小软件都会触发 Windows SmartScreen 提示，点 "更多信息 → 仍要运行" 即可。源码完全开放，可自行审计。

怎么卸载？

直接删除下载的 .exe 即可，没有安装程序、不写注册表。如需彻底清理配置，再删除 %APPDATA%\PurrPause\ 文件夹。

我的数据存在哪里？会上传吗？

不会上传。所有配置只保存在你本机的 %APPDATA%\PurrPause\config.json。v0.1.x 运行时不发起任何网络请求。

支持 macOS 吗？

macOS 版本目前暂未发布，将在后续小版本中补充。Mac 用户现在可以从 源码 运行。

可以换成自己的猫吗？

可以。右键托盘 🐱 → "设置"，填写任意 GIF/PNG 的绝对路径，即可替换休息卡片左侧的缩略图。还能调整工作间隔与休息时长。
