# Changelog

All notable changes to Purr Pause will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] — 2026-06-12

### Changed
- Rebuilt the rest-break cat animation from a cleaner 4K source: walk frames doubled to 30 fps, a seamless ping-pong idle loop (no visible jump at the seam), and drift-free time-based playback with a pre-scaled frame cache and dirty-rectangle repaint — noticeably smoother motion at lower CPU.
- The cat animation now elastically matches the configured rest duration (10–60 s) instead of running a fixed length, so the cat never walks off early or leaves dead time.

### Fixed
- Dismissing the rest card with the × button now lets the cat walk out gracefully instead of stranding the full-screen overlay and silently dropping every subsequent rest reminder for the session.

## [0.1.0] — 2026-05-31

### Added
- First public release on Windows.
- 20-20-20 rest reminder timer with configurable interval and rest duration.
- Animated cat sprite sequence — walk-in → idle → walk-out, 206 PNG frames at 12–15 fps.
- System tray icon with menu (Show settings / Quit).
- Settings dialog (rest interval minutes, rest duration seconds, optional custom GIF path).
- Single-file Windows .exe built via PyInstaller (`PurrPause-0.1.0-windows.exe`).
- Tag-triggered GitHub Actions release workflow (`.github/workflows/release.yml`).
- MIT License.
- Bilingual README (Chinese + English).
- Asset attribution document (`ASSETS.md`).

### Known issues
- macOS .dmg build is intentionally disabled in CI for v0.1.x. The `make_icns()` helper renders 🐱 below Apple Color Emoji's smallest sbix bitmap size, causing `OSError: invalid pixel size`. Tracked for a v0.1.x patch.
- The bundled `assets/cat.gif` uses placeholder frames generated by `scripts/make_placeholder_cat.py`; the high-quality cat animation lives in `assets/cat_anim/*.png` and is what users actually see.
